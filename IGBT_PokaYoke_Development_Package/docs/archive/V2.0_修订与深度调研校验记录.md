## 3. 重要修正

| 修正项 | 修正原因 |
|---|---|
| 不再把 V 型治具作为默认工位 | 用户明确说明操作员站立，双手持管两端 |
| 拆分 `hand_or_pen` | 人手/手套与笔是不同实体和不同业务证据 |
| 不使用“全图没有标签 = 已撕掉” | 翻面、遮挡、移出视野和失焦会造成相同表象 |
| `unknown` 改为运行时拒识状态/挑战样本 | unknown 本身是异质集合，不是稳定的单一视觉类别 |
| C 的计时必须等手离开且视角有效 | 避免手遮挡期间累计 1.2 秒 |
| 1.2 秒使用单调时钟和采集时间戳 | 防止系统时间变化、推理排队和丢帧污染计时 |
| 不把 OpenCV `set()` 当成相机锁定成功 | 必须设备能力查询、读回、实拍稳定性验证 |
| 重算 C920 FOV | 70.42° 水平视角下，1m 工作距离理论水平覆盖约 1.41m，不是约 1m；标签像素密度会明显下降 |
| C 自动放行增加方向基准条件 | 标签撕除后，标签本身不能再证明标签面朝向，需其他可观测方向基准或工艺约束 |

## 5. 仍需现场验证、不能由文档代替的事项

- 相机到标签面的实际工作距离、FOV、标签原始像素宽高。
- C920 当前 Windows 驱动对 Focus/Exposure/White Balance/Gain 的真实支持范围。
- 操作员是否会绕料管轴线旋转，以及是否可完成标签面正向展示。
- 标签撕掉后能否使用仍可见的方向基准；如果没有，单台正面摄像头的 C 自动放行应暂停。
- A 划线和 B 覆盖的工艺合格边界。
- 黄管/蓝管是否还有更多色号、材料批次、厚度变化。
- 白色手套的款式变化和实际手部检测可行性。
- 反光抑制方案与 ESD 工作台要求是否兼容。
- 可接受的 FAR/FRR 和独立测试周期数量，由工艺/质量部门批准。

本记录不把推断替代现场试验，也不构成法律意见或功能安全认证。
