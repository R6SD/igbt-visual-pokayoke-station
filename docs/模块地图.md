# 模块地图与修改波及面

| 模块 | 核心文件 | 直接依赖 | 修改波及面（改前必查） |
| :--- | :--- | :--- | :--- |
| **common** | `cpp_backend/include/igbt/common.hpp` | Win32 API、OpenCV/JSON | 全后端所有模块头文件，改动会触发全量重编 |
| **database** | `cpp_backend/include/igbt/database.hpp`, `src/database.cpp`, `src/db/red_rabbit_audit_repo.cpp`, `src/db/mes_outbox_repo.cpp` | `common`、SQLite3 WAL | `http_server`（配置/查询/导出/红兔审计/MES Outbox）、`red_rabbit`（金样与审计落库）、`mes`（事务发件箱与签批 Lot）、`fsm`（状态落库）、`training_manager`（样本统计） |
| **vision_engine** | `cpp_backend/include/igbt/vision_engine.hpp`, `src/vision_engine.cpp`, `include/igbt/vision/tube_geometry.hpp`, `src/vision/tube_geometry.cpp`, `include/igbt/vision/hand_glove_detector.hpp`, `src/vision/hand_glove_detector.cpp`, `include/igbt/vision/label_ood_classifier.hpp`, `src/vision/label_ood_classifier.cpp` | `common`、DirectShow、OpenCV `calib3d`/`dnn`/`ml` | `fsm`（`TUBE_ALIGN_FAIL`/`TUBE_ALIGN_LOW_CONF`/`ood_rejected` 与 `STATE_OOD_UNKNOWN`）、`http_server`（MJPEG 流、`/api/vision/pipeline_status`、`/api/models/hand_glove/load`、`/api/models/ood/*`）、`training_manager`（特征与 OOD 标定一致性） |
| **fsm** | `cpp_backend/include/igbt/fsm.hpp`, `src/fsm.cpp` | `common`、`vision_engine`、`database` | `http_server`（状态轮询与复位接口）、`OperatorView` / `Andon` 告警状态（含 OOD 冻结与 5 帧闭锁及 `MES_*` 原因文本） |
| **hal** | `cpp_backend/include/igbt/industrial_hal.hpp`, `include/igbt/hal/adam_modbus_dio.hpp`, `src/hal/adam_modbus_dio.cpp` | `common`、Winsock2 (`ws2_32`) | `http_server`（`/api/hal/dio`、看门狗故障落锁与 `WATCHDOG_FAULT_LOCK` 审计）、`vision_engine`（心跳时间戳）、`mes`（`MesWorkOrder` / `IMesClient`） |
| **mes** | `cpp_backend/include/igbt/mes/mes_sync_worker.hpp`, `src/mes/mes_sync_worker.cpp`, `src/db/mes_outbox_repo.cpp` | `common`、`industrial_hal`、`database`、`cpp-httplib` | `http_server`（`/api/mes/*`、`/api/state` 分级闭锁）、`red_rabbit`（换批自动触发 `LOT_CHANGE`）、`interlock`（断联/追回/管色防混料闭锁）、`MesOutboxPanel` / `MesRecallOverlay` |
| **red_rabbit** | `cpp_backend/include/igbt/red_rabbit.hpp`, `src/red_rabbit.cpp` | `common`、`database`、`industrial_hal` | `http_server`（`/api/state` 放行阻断、`/api/red_rabbit/*`、光学/模型/OOD/换批变更触发、透传 `ood_energy`/`ood_mahalanobis`）、`RedRabbitOverlay` |
| **training_manager** | `cpp_backend/include/igbt/training_manager.hpp`, `src/training_manager.cpp`, `include/igbt/training/onnx_model_registry.hpp`, `src/training/onnx_model_registry.cpp` | `common`、`database`、`label_ood_classifier`、OpenCV | `vision_engine`（热加载模型权重与 `ood_calibration.json`）、`http_server`（训练/数据集/ONNX 导入/OOD 标定 API）、`App.tsx` / `LabelOodCard.tsx` |
| **http_server** | `cpp_backend/include/igbt/http_server.hpp`, `src/http_server.cpp` | 以上全部后端模块、`cpp-httplib`、`web/dist` | 前端全站 API 契约（含 `/api/mes/*`）、`start_local_ui.ps1` 端口与鉴权 |
| **main** | `cpp_backend/src/main.cpp` | `http_server` | 服务启动参数、工作目录与优雅退出信号 |
| **HMI 主应用** | `frontend/.../src/App.tsx`, `src/components/*`, `src/features/red-rabbit/*`, `src/features/training/LabelOodCard.tsx`, `src/features/audit/*` | `http_server` REST/MJPEG 接口、`index.css` | 修改后必须执行 `npm run build` 刷新 `IGBT_PokaYoke_Development_Package/web/dist` |
| **样式与焦点** | `frontend/.../src/index.css` | Tailwind v4 主题变量 | 全站三档字号（24/16/14px）、暗色对比度与滚动裁剪焦点框 |
