# 模块地图与修改波及面

| 模块 | 核心文件 | 直接依赖 | 修改波及面（改前必查） |
| :--- | :--- | :--- | :--- |
| **common** | `cpp_backend/include/igbt/common.hpp` | Win32 API、OpenCV/JSON | 全后端所有模块头文件，改动会触发全量重编 |
| **database** | `cpp_backend/include/igbt/database.hpp`, `src/database.cpp`, `src/db/red_rabbit_audit_repo.cpp` | `common`、SQLite3 WAL | `http_server`（配置/查询/导出/红兔审计）、`red_rabbit`（金样与审计落库）、`fsm`（状态落库）、`training_manager`（样本统计） |
| **vision_engine** | `cpp_backend/include/igbt/vision_engine.hpp`, `src/vision_engine.cpp` | `common`、DirectShow、OpenCV `dnn`/`ml` | `fsm`（帧级推理输入）、`http_server`（MJPEG 流与标定 ROI 接口）、`training_manager`（特征一致性） |
| **fsm** | `cpp_backend/include/igbt/fsm.hpp`, `src/fsm.cpp` | `common`、`vision_engine`、`database` | `http_server`（状态轮询与复位接口）、`OperatorView` / `Andon` 告警状态 |
| **hal** | `cpp_backend/include/igbt/industrial_hal.hpp`, `include/igbt/hal/adam_modbus_dio.hpp`, `src/hal/adam_modbus_dio.cpp` | `common`、Winsock2 (`ws2_32`) | `http_server`（`/api/hal/dio`、看门狗故障落锁与 `WATCHDOG_FAULT_LOCK` 审计）、`vision_engine`（心跳时间戳） |
| **red_rabbit** | `cpp_backend/include/igbt/red_rabbit.hpp`, `src/red_rabbit.cpp` | `common`、`database`、`industrial_hal` | `http_server`（`/api/state` 放行阻断、`/api/red_rabbit/*`、光学/模型变更触发）、`RedRabbitOverlay` |
| **training_manager** | `cpp_backend/include/igbt/training_manager.hpp`, `src/training_manager.cpp` | `common`、`database`、OpenCV | `vision_engine`（热加载模型权重）、`http_server`（训练/数据集 API）、`App.tsx` 训练步骤页 |
| **http_server** | `cpp_backend/include/igbt/http_server.hpp`, `src/http_server.cpp` | 以上全部后端模块、`cpp-httplib`、`web/dist` | 前端全站 API 契约、`start_local_ui.ps1` 端口与鉴权 |
| **main** | `cpp_backend/src/main.cpp` | `http_server` | 服务启动参数、工作目录与优雅退出信号 |
| **HMI 主应用** | `frontend/.../src/App.tsx`, `src/components/*`, `src/features/red-rabbit/*` | `http_server` REST/MJPEG 接口、`index.css` | 修改后必须执行 `npm run build` 刷新 `IGBT_PokaYoke_Development_Package/web/dist` |
| **样式与焦点** | `frontend/.../src/index.css` | Tailwind v4 主题变量 | 全站三档字号（24/16/14px）、暗色对比度与滚动裁剪焦点框 |
